SET IPTV installeren en activeren: de complete handleiding voor 2026

8 Augustus 2026 • Door Diamond IPTV Redactie • 11 min leestijd

Inleiding: Een van de populairste apps op Samsung & LG TV's

Bezit je een Samsung Smart TV (Tizen OS) of een LG Smart TV (WebOS) en zoek je een stabiele, overzichtelijke en snelle applicatie om IPTV te kijken zonder dat je een losse tv-box hoeft te kopen? Dan is SET IPTV een van de allerbeste keuzes op de markt. Met zijn strakke interface, snelle zapsnelheid en uitstekende ondersteuning voor EPG-gidsen is het de favoriet van duizenden Nederlandse tv-kijkers.

Maar hoe pak je SET IPTV installeren en activeren precies aan? Omdat het koppelen van de afspeellijst niet op de TV zelf gebeurt maar via de officiële website van SET IPTV met behulp van jouw unieke MAC-adres, leggen we in dit artikel stap-voor-stap uit hoe je dit binnen 5 minuten foutloos instelt.

Wat is SET IPTV en hoe werkt het?

SET IPTV is een zogenaamde *media player applicatie*. De app bevat van zichzelf geen tv-zenders of films. Het fungeert als de geavanceerde videospeler op jouw televisie waarin je jouw abonnement van Diamond IPTV laadt.

Het unieke aan SET IPTV is dat de app werkt op basis van het **MAC-adres** (Media Access Control) van jouw televisietoestel. Bij het opstarten van de app zie je dit unieke MAC-adres op je tv-scherm staan (bijvoorbeeld aa:bb:cc:11:22:33). Via het online beheer-portal van SET IPTV koppel je vervolgens jouw M3U-link of Xtream Codes gegevens aan dit specifieke MAC-adres.

Wil je meer weten over hoe IPTV streaming technisch werkt? Bekijk ons overzichtsartikel Wat is IPTV en hoe werkt het?.

📺 Gratis Proefperiode van SET IPTV:

Wanneer je SET IPTV voor het eerst downloadt op je Smart TV, krijg je automatisch een **gratis proefperiode van 7 dagen** om de app uit te testen. Na 7 dagen vraagt de ontwikkelaar een eenmalige activatievergoeding van circa €15,99 voor levenslang gebruik.

Stap 1: SET IPTV Downloaden op jouw Smart TV

SET IPTV is officieel goedgekeurd en beschikbaar in de app stores van vrijwel alle grote tv-merken:

Op Samsung Smart TV (Tizen OS 2017 of nieuwer):

  1. Druk op de Home-knop van je Samsung afstandsbediening en open Apps.
  2. Zoek in de Samsung App Store naar SET IPTV. (Raadpleeg ook de informatie op Samsung Support Nederland voor tv-app downloads).
  3. Klik op Downloaden / Installeren en open de applicatie.

Op LG Smart TV (WebOS):

  1. Open de LG Content Store via het startmenu van je LG afstandsbediening.
  2. Typ SET IPTV in de zoekbalk. Informatie over LG-apps vind je op de officiële LG Content Store portal.
  3. Klik op Installeren en start de app.

Op Android TV / Google TV / Firestick:

Open de Google Play Store of gebruik de app Downloader om te zoeken naar SET IPTV en installeer de applicatie direct op je apparaat.

Lees voor meer Samsung-specifieke tips ons artikel IPTV Installeren op Samsung TV.

Stap 2: Het MAC-Adres van je TV Noteren

Zodra je SET IPTV voor het eerst opent op je televisie, verschijnt er een overzichtelijk blauw/donker startscherm. Op dit scherm zie je de volgende twee cruciale gegevens:

  • TV MAC Address: Een uniek 12-cijferig adres (bijvoorbeeld 00:1A:79:XX:XX:XX of a4:b2:c8:...).
  • App Status: 7 days free trial.

Laat de app openstaan op je tv-scherm of noteer het MAC-adres nauwkeurig op een papiertje of je mobiele telefoon.

Stap 3: Jouw IPTV Abonnement Uploaden via het Webportal

Pak nu je smartphone, laptop of pc en volg dit stappenplan om je Diamond IPTV abonnement te koppelen aan je televisie:

  1. Ga op je telefoon of computer naar de officiële uploadpagina van SET IPTV: https://cms.setiptv.com/set.app.
  2. Navigeer naar het gedeelte "Upload M3U / Xtream playlist".
  3. Vul in het vakje "TV MAC address" het exacte MAC-adres in dat op jouw televisie getoond wordt.
  4. Kies bij inlogmethode voor **Xtream Codes** (Aanbevolen) of **Link (M3U URL)**:
    • Bij Xtream Codes: Vul de Server URL, Username en Password in die je in jouw activatie-mail van Diamond IPTV hebt ontvangen. (Lees in onze gids Wat zijn Xtream Codes? waarom deze optie het snelst laadt).
    • Bij M3U Link: Plak je unieke M3U-afspeellijst link in het veld *URL*.
  5. Vink de Captcha-beveiliging "Ik ben geen robot" aan.
  6. Klik op de groene knop Send / Upload.

🔄 Herstart de App op je Televisie!

Nadat de melding "Success! Playlist uploaded successfully" op het scherm van je telefoon verschijnt, ga je terug naar je televisie. Druk op de afstandsbediening op de knop **Reload / Restart (of herstart de app)**. De zenders, EPG-gids en VOD films worden nu geladen!

Stap 4: SET IPTV Definitief Activeren (Licentie Kopen)

Na de gratis proefperiode van 7 dagen stopt de app met het laden van de streams en verschijnt de melding "Trial expired". Om te blijven kijken moet je de eenmalige licentie activeren op je MAC-adres:

  1. Ga op je smartphone of pc naar de activatiepagina: https://cms.setiptv.com/act.app.
  2. Vul jouw TV MAC Address in.
  3. Vul jouw e-mailadres in ter bevestiging.
  4. Kies een betaalmethode (zoals iDEAL, Creditcard of PayPal) en voltooi de betaling van €15,99.
  5. Zodra de betaling is afgerond is jouw MAC-adres levenslang geactiveerd. Je hoeft de app nooit meer opnieuw te kopen!

Handige Instellingen in SET IPTV voor de Beste Beeldkwaliteit

Om te zorgen dat snelle sportwedstrijden (zoals de Eredivisie en Formule 1) en 4K VOD films soepel afspelen op jouw Smart TV, kun je een paar instellingen in het menu van SET IPTV aanpassen:

  • Stream Format: Zet het formaat in de instellingen op HLS of TS. HLS laadt sneller bij schommelende internetsnelheden.
  • EPG Language: Zet de taal van de gids op Dutch (Nederlands) voor de juiste zenderinformatie.
  • Internal Player vs External Player: Gebruik op Samsung/LG de standaard *Internal HW Player*. (Lees meer over mediacodecs in onze gids ExoPlayer versus VLC Player voor IPTV).

Veelgestelde Vragen over SET IPTV (FAQ)

Wat als ik een typefout heb gemaakt bij het invoeren van het MAC-adres?

Als je een verkeerd MAC-adres hebt ingevuld op de website, worden de zenders geüpload naar de verkeerde tv. Ga eenvoudig opnieuw naar cms.setiptv.com, voer het juiste MAC-adres in en klik op Delete Playlist of upload de link opnieuw.

Moet ik SET IPTV opnieuw kopen als ik een nieuwe TV aanschaf?

Omdat de licentie gekoppeld is aan het unieke hardwarematige MAC-adres van je oude tv, geldt de licentie voor die specifieke tv. Bij een nieuwe tv download je SET IPTV opnieuw op het nieuwe MAC-adres.

Waar kan ik een betrouwbaar IPTV abonnement aanschaffen voor SET IPTV?

Bij Diamond IPTV ontvang je direct een kant-en-klare M3U link en Xtream inlog. Bekijk ons complete zenderaanbod op onze IPTV Kopen pagina.
